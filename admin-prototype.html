Управление работами

Безопасный прототип. Пока данные не отправляются в GitHub. Форма работает только в твоём браузере: можно заполнить карточку, выбрать фотографии и посмотреть результат. Для записи потребуется личный fine-grained токен GitHub с доступом только к тестовому репозиторию. Он вводится вручную, хранится лишь в памяти открытой страницы и не записывается в файлы сайта.

Подключение GitHub

Для теста нужен fine-grained personal access token GitHub: только репозиторий pm-gallery-preview, разрешение Contents: Read and write. Никогда не отправляй токен в чат и не сохраняй его в исходном коде. Введённый токен исчезнет при перезагрузке страницы.

Новая работа

Фотографии отправятся в тестовый репозиторий только после нажатия «Сохранить на GitHub». Для первого теста выбери 1–2 JPEG/PNG/WebP до 2 МБ каждый.

Предпросмотр

Предпросмотр не публикует работу. Для публикации нажми «Сохранить на GitHub».
